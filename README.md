# Yapilacaklar Listesi

Todo-App-Yavuzlar, HTML + CSS + JS (Vanilla) kullanıldı.

## Özellikler

- Görev ekleme
- Görev silme
- Görev düzenleme
- Görev arama
- Etiket sistemi (Acil, İş, Kişisel, Alışveriş, Sağlık, Eğitim)
- Etikete göre filtreleme
- LocalStorage ile veri saklama

## Kullanım

index.html dosyasını tarayıcıda aç. Hepsi bu kadar.

## Teknolojiler

- HTML5
- CSS3
- JavaScript (Vanilla)

## Notlar

- Veriler tarayıcının localStorage'ında saklanıyor
- Regex korumalı todo-app-yavuzlar özeline
